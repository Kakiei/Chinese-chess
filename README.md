# Chinese Chess

A responsive Chinese chess game for desktop, tablet, and mobile browsers.

## Features

- Play against the computer with five difficulty levels.
- Play pass-and-play with two people on one device.
- Legal move indicators, move history, hints, undo, and board flip.
- Optional move sounds and a light/dark appearance switch.
- Finished matches, scores, and full move records are stored in the browser with IndexedDB, with local storage as a fallback.

## Run locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

The game is a static site. In the repository settings, enable GitHub Pages from the `main` branch and the root folder. The site URL is:

https://kakiei.github.io/Chinese-chess/

Match archives are local to each browser and do not sync between devices.
